# V5.2 FIX: LỖI HIỂN THỊ "THỦ CÔNG"

**Date:** 2026-03-02  
**Issue:** SELL signals hiển thị "⚪ Thủ công" thay vì "Cắt lỗ" hoặc "Chốt lời"  
**Status:** ✅ FIXED  

---

## 🔴 VẤN ĐỀ

**Screenshot cho thấy:**
```
✅ BCM: "🔴 Cắt lỗ (SL)" - OK
✅ VSC: "🟢 Chốt lời (TP)" - OK
❌ PVB: "⚪ Thủ công" - SAI! (should be Chốt lời)
❌ PET: "⚪ Thủ công" - SAI!
❌ PC1: "⚪ Thủ công" - SAI!
❌ KDC: "⚪ Thủ công" - SAI!
```

**Root cause:**

V5.2 push strategy codes mà frontend KHÔNG nhận diện:
```python
# V5.2 push:
'strategy': 'TAKE_PROFIT_1'  # ❌ Frontend không biết
'strategy': 'TAKE_PROFIT_2'  # ❌ Frontend không biết
'strategy': 'MA20_STRICT'    # ❌ Frontend không biết
'strategy': 'TP_PULLBACK'    # ❌ Frontend không biết
'strategy': 'TRAILING_STOP'  # ❌ Frontend không biết

# Frontend expect:
'strategy': 'TAKE_PROFIT'    # ✅ Hiển thị "Chốt lời (TP)"
'strategy': 'STOP_LOSS'      # ✅ Hiển thị "Cắt lỗ (SL)"
'strategy': 'MA20_BREAK'     # ✅ Hiển thị "MA20 Break"
```

**Kết quả:** Frontend không match → Hiển thị mặc định "Thủ công"

## ✅ GIẢI PHÁP

**Map V5.2 codes → Frontend codes:**

```python
# NEW: Strategy mapping
STRATEGY_MAP = {
    'STOP_LOSS': 'STOP_LOSS',              # Cắt lỗ
    'TAKE_PROFIT_1': 'TAKE_PROFIT',        # Chốt lời TP1 → TAKE_PROFIT
    'TAKE_PROFIT_2': 'TAKE_PROFIT',        # Chốt lời TP2 → TAKE_PROFIT
    'TP_PULLBACK': 'TAKE_PROFIT',          # TP Pullback → TAKE_PROFIT
    'TRAILING_STOP': 'TAKE_PROFIT',        # Trailing → TAKE_PROFIT
    'MA20_STRICT': 'MA20_BREAK',           # MA20 Strict → MA20_BREAK
}

exit_reason = sell_signal['exit_reason']
frontend_strategy = STRATEGY_MAP.get(exit_reason, exit_reason)

payload = {
    ...
    'strategy': frontend_strategy,  # ← Frontend-compatible
    'note': f"{exit_reason} ({exit_pct}%)",  # ← Chi tiết trong note
}
```
